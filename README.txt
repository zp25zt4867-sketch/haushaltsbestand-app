Haushaltsbestand – iPhone-Version
Diese Version ist als iPhone-Web-App (PWA) gedacht und kann über Safari zum Home-Bildschirm hinzugefügt werden.
Wichtig: Für die Kamerafunktion muss die App über HTTPS oder einen sicheren App-Host geöffnet werden.
Der Barcode-Scanner nutzt ZXing über unpkg.com und benötigt beim ersten Laden Internet.
